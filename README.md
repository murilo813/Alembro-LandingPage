# Alembro - Landing Page 🚀

Landing Page da Alembro Tech & Systems
[Alembro](https://murilo813.github.io/Alembro-LandingPage/)

## Estrutura do projeto

```
├── index.html          # página principal (raiz, exigido pelo GitHub Pages)
├── 404.html             # página de erro (raiz, exigido pelo GitHub Pages)
├── CNAME
├── robots.txt
├── sitemap.xml
├── pages/               # páginas secundárias
│   ├── privacy.html
│   ├── delete.html
│   └── thanks.html
├── assets/
│   ├── images/          # favicon e imagens (.webp)
│   └── css/             # styles.css
└── services/            # integração com o backend/API
    ├── api.js
    └── README.md
```

> `index.html` e `404.html` precisam continuar na raiz do repositório — é onde o GitHub Pages procura por eles.

## Atenção: URLs mudaram

`privacy.html` e `delete.html` foram movidos para `/pages/`. As URLs públicas passaram a ser:

- `https://alembro.com/pages/privacy.html`
- `https://alembro.com/pages/delete.html`

Se essas URLs estiverem cadastradas na Play Store / App Store (política de privacidade, exclusão de conta) ou em qualquer outro lugar fora deste repositório, atualize os links lá.
